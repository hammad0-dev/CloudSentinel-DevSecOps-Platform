Also configure INFRA_STATE_BUCKET / INFRA_FLOW_LOG_BUCKET_ARN to matching values,

Snap-accessible path (e.g. ~/snap/trivy/common/cloudsentinel-plans) for Snap Trivy.
Do not copy Terraform state into these workspaces. Backend main.tf.json is server
controlled with exact project/environment key, encryption, native locking,
account/region restrictions and only the trusted network module.
