## Contract amendment 1.1\n\nThe lifecycle contract now requires createOwnedFixtureNetwork(scanIdentity, networkSpec), verifyOwnedFixtureNetwork(reference, freshObservation), provision({projectId, executionId, scanId, target, fixtureNetworkReference}), and cleanup(scanId). Native Docker inputs are docker inspect/network inspect JSON; routes use ip route list, ip -f inet6 route list, and ip address show. Native BusyBox text is parsed strictly and matched to fresh Docker endpoint identity, address, prefix, and MAC evidence. Squid activation requires canonical UTF-8 policy bytes, SHA-256 digest, read-only mount, explicit config path, process/readiness evidence, and policy-file digest match. Connectivity probes carry source ID, destination hostname/IP/port, protocol, method, expected/actual result, exit/status, network evidence, timestamp, and provenance. Cleanup re-inspects exact IDs and cloudsentinel.owner/cloudsentinel.scan labels; foreign, substituted, or unlabeled objects are never deleted. Runtime containment remains unverified until the future disposable test.
